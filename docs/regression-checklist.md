# Capri: Regression Checklist

This checklist must be verified at the end of each development stage before creating the stage git commit and submitting the stage report.

---

## 1. Automated Build & Quality Gate

- [x] **TypeScript Typecheck:** `npm run typecheck` (`tsc --noEmit`) passes with zero errors and warnings under strict mode.
- [x] **Frontend Linting & Formatting:** ESLint / Prettier check passes cleanly with no violations.
- [x] **Frontend Tests:** Unit and integration tests (`vitest` / `npm test`) pass.
- [x] **Python Linting & Formatting:** `ruff check .` and `ruff format --check .` pass with zero diagnostics.
- [x] **Python Typecheck:** `mypy` or strict type analysis passes on the brain codebase.
- [x] **Python Tests:** `pytest` passes 100% of test cases.
- [x] **Git Working Tree:** Clean status (`git status`), no untracked build artifacts, logs, `.env` or temporary files.

---

## 2. Process Lifecycle & IPC Link

- [x] **Electron Startup:** App launches cleanly, creates transparent frameless overlay window at `screen-saver` level.
- [x] **Brain Process Spawn:** Electron successfully spawns `brain` child process using Python 3.12.
- [x] **Dynamic WS Handshake:**
  - Random localhost port and random cryptographic token generated by Electron.
  - Token verified upon connection; non-matching or external connections rejected with HTTP 403 / WS close.
- [x] **Heartbeat & Reconnect:** Heartbeat ping/pong active; if brain process terminates abruptly, Electron detects exit and restarts it gracefully within backoff limit.
- [x] **Clean Teardown:** Closing Electron (via Tray -> Quit or single-instance conflict) cleanly terminates the child Python process with no orphan processes remaining.
- [x] **Offline State:** Character visually reflects "offline" / disconnected construct state if the brain connection is lost.

---

## 3. Hit-Testing, Click-Through & Input Routing

- [x] **Click-Through Transparency:** Clicking through transparent regions of the desktop reaches windows and icons underneath without delay or interception.
- [x] **Pixel-Precise Hit Testing:** Clicks directly over Capri's visible sprite body (alpha > 40) or open UI panels trigger interaction.
- [x] **Adaptive Polling:** Mouse cursor polling is throttled to ~30 Hz only when near the character or active panel rects, dropping to low-frequency polling otherwise.
- [x] **Input Focus Toggle:** Overlay is not focusable by default (`focusable: false`); focus is enabled only when a text input is active, releasing focus back on submit/blur/Esc.
- [x] **Mouse Hook Resilience:** Rearm mechanism recovers gracefully if Windows silently drops the mouse hook after sleep, screen lock, or display resolution changes.

---

## 4. Multi-Monitor, Per-Monitor DPI & Window Tracking

- [x] **Multi-Monitor Display:** Overlay positions correctly on the configured display; drags across monitors adapt coordinate space accurately.
- [x] **Per-Monitor DPI:** Renders crisply at different DPI scalings (e.g. 100%, 125%, 150%, 200%) without blurry textures or misplaced hitboxes.
- [x] **Window Geometry Watcher:**
  - `windows.ps1` helper reads frame bounds and z-order without reading window titles or contents.
  - Physical coordinates are converted to DIPs via `screenToDipRect`.
  - Minimized, cloaked, tool, or own windows are filtered out.
- [x] **Perch & Fall:** Capri sits on window ledges, tracks moving windows, and transitions to falling when a window closes or is covered.

---

## 5. Performance, Memory & Resource Budget

- [x] **Idle CPU Consumption:** Total idle CPU usage (Electron + Python Brain combined) stays strictly below 2.0%.
- [x] **Stowed / Hidden CPU:** When stowed as a biochip (`Ctrl+Alt+C`) or hidden, CPU usage drops to ~0%.
- [x] **Rendering Cap:** Character animations cap at 12 fps on twos, 24 fps on action beats; no unbounded requestAnimationFrame loops when static.
- [x] **Memory Stability:** Heap size remains stable over runtime without leaks.
- [x] **Offline Operation:** No external requests made without explicit user instruction; fonts and basic assets loaded locally.

---

## 6. Visual Fidelity & Accessibility (WCAG 2.3.1)

- [x] **Cel Animation Feel:** Poses step cleanly according to exposure sheets (`acting.js`); no unintentional linear lerp or easing applied to character body drawings.
- [x] **Line Boil:** Subtle line boil active on twos without distracting jitter.
- [x] **Reduce Motion Mode:**
  - Follows Windows "Animation effects" accessibility setting automatically.
  - Manual toggle available in menu.
  - When enabled, high-frequency glitch, screen shake, and impact flashes are replaced with smooth opacity fades.
  - Glitch frequency capped (`maxGlitchPerMinute <= 3`), zero flashing faster than 3 times per second.

---

## 7. Safety, Sandboxing & Credential Integrity

- [x] **Path Sandboxing:** File operations (`list_dir`, `read_file`, `write_file`, `edit_file`) strictly confined to `allowed_dirs`; path traversal (`..`), absolute escapes, and symlink breaks are rejected.
- [x] **Destructive Action Block:** File deletion, git history rewriting, and arbitrary system configuration changes are completely disallowed.
- [x] **Strict Approval Gate:**
  - `write_file`, `edit_file`, `run_python`, `close_app` always require explicit UI button click from the user.
  - Keyboard auto-confirmations or automatic approve timeouts are strictly forbidden.
- [x] **Prompt Injection Mitigation:** Untrusted file or web content is isolated within data envelopes, instructing the LLM to ignore embedded commands.
- [x] **Credential Security:** API keys stored exclusively in Windows Credential Manager via `keyring`. Zero plain-text keys in logs, config files, git commits, or IPC messages.
- [x] **Action Logging:** All executed actions logged to `actions.log` with timestamps, action kind, and status, without recording secrets or sensitive file payloads.

---

## 8. Settings Panel & Distribution Packaging

- [x] **Settings Panel:**
  - Interactive modal dialog with model selection, daily USD budget limit, motion mode (`auto`, `full`, `reduced`), scale and volume sliders, voice & mute toggles, and OpenRouter API key configuration.
  - Settings persisted across restarts in `%APPDATA%\Capri\config.json`.
  - Dynamic live propagation of settings (`daily_budget_usd`, `model`) to Python brain via `settings_update` message.
- [x] **Standalone Brain Distribution:**
  - PyInstaller configuration (`brain/brain.spec`) bundles Python 3.12 runtime, faster-whisper, edge-tts, keyring, websockets, and json schemas into standalone `brain.exe`.
  - Electron main process detects packaged mode and spawns `resources/brain/brain.exe` in production, falling back to local Python `.venv` in development.
- [x] **Installer Packaging:**
  - `electron-builder` configuration for Windows NSIS installer with desktop/start-menu shortcuts and custom Capri icon.

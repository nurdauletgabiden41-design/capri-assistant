# Capri: настольный AI-ассистент (Electron + Python Brain)

**Capri** — это персональный настольный AI-ассистент для Windows 11, воплощенный в виде аниме-персонажа (Капри / Project Capricorn из вселенной Cyberpunk). Она живет прямо на экране вашего рабочего стола поверх окон, реагирует на происходящее, управляет компьютером по голосовым и текстовым командам (запуск программ и сайтов, управление музыкой, работа с файлами, выполнение Python-скриптов с ручным подтверждением), комментирует действия и озвучивает реплики.

---

## 1. Архитектура проекта

Проект разделен на два изолированных процесса:

```text
capri-assistant/
├─ app/          Electron + TypeScript: оверлей, WebGL-риг персонажа, визуальные эффекты, UI-панели, трей, глобальные хоткеи, отслеживание геометрии окон
├─ brain/        Python 3.12: LLM-клиент (OpenRouter / локальные модели), характер и персона, реестр инструментов, безопасность и песочница, голос (STT/TTS), память и метрики
├─ shared/       protocol.md + JSON-схемы сообщений (единый контракт взаимодействия между процессами)
├─ docs/         Архитектурная документация, дизайн-заметки, реестр ассетов, чек-листы регрессии
└─ reference/    Локальные клоны референсных репозиториев (только чтение, в .gitignore)
```

### Связь процессов (IPC)
- Electron выступает управляющим хостом («лицо»): при запуске он порождает процесс Python Brain как дочерний процесс, контролирует его жизненный цикл и перезапускает в случае сбоя.
- Взаимодействие происходит по локальному WebSocket на `127.0.0.1` со случайным свободным портом и криптографически стойким токеном авторизации, передаваемыми Python через переменные окружения при спавне.
- Подключения без токена или из внешних интерфейсов немедленно отклоняются.
- Формат сообщений: валидируемый JSON по схемам `shared/schemas/*.json`.

## 2. Ключевые приоритеты

1. **Красота и визуальная достоверность (Art Direction Studio Trigger):**
   - Рендеринг персонажа на чистом TypeScript + WebGL-шейдер (без лишних ререндеров React на каждый кадр).
   - Традиционная покадровая анимация «на двойках» (12 fps) и «на единицах» (24 fps при телепортации) с легким line boil (эффект дрожания живой карандашной линии).
   - Принцип «pose-to-pose»: отсутствие плавных искусственных твинов, экспозиционные листы (`acting`), упреждение (anticipation), смаз-кадры (smears), остаточные изображения (afterimages), перехлесты (overshoot).
   - Фиолетовое смещение контуров (misregistration), глитчи реликвии, cut-in экраны с эмоциями.

2. **Практичность, производительность и легкость:**
   - Потребление CPU в покое < 2%, около 0% в свернутом режиме (биочип).
   - Пиксельно-точный click-through: пустые области окна Electron полностью пропускают клики в приложения под ним.
   - Экономия токенов: жесткий контроль контекста, сжатие истории, кеширование промптов, лимиты суточного бюджета.
   - Независимость от внешних CDN: шрифты (Chakra Petch, JetBrains Mono) и звуки поставляются локально или синтезируются на лету через Web Audio API.

3. **Бескомпромиссная безопасность:**
   - **Защита от случайных разрушений:** персонаж никогда не удаляет файлы, не переписывает историю git, не читает переменные среды и секреты.
   - **Только геометрия:** отслеживание окон Windows считывает исключительно физические координаты и размеры окон, без доступа к заголовкам и содержимому.
   - **Ручное подтверждение (Approval Flow):** опасные операции (запись файлов, запуск Python-кода, закрытие программ) требуют явного клика мыши пользователя в панели подтверждения. Никаких тайм-аутов авто-одобрения.
   - **Хранение секретов:** API-ключи хранятся исключительно в Windows Credential Manager через библиотеку `keyring`.

## 3. Этапы разработки

- **Этап 0:** Исследование референсов и проектирование (протокол, архитектура, список ассетов, чек-листы).
- **Этап 1:** Базовый каркас (Electron-оверлей, click-through, спавн Python Brain, WS-рукопожатие, демо-режим).
- **Этап 2:** Персонаж (TypeScript WebGL-риг, экспозиционные листы, 8 эмоций, оптимизация fps).
- **Этап 3:** Поведение и окна (сидение на окнах, падение, подглядывание, реакция на курсор, перетаскивание).
- **Этап 4:** Эффекты, панели и звук (шейдерные FX, тикер действий, Web Audio синтезатор звуков).
- **Этап 5:** Мозг ассистента (OpenRouter API, системный промпт персоны Capri, память SQLite, учет токенов).
- **Этап 6:** Инструменты и безопасность (песочница файловой системы, браузер, мультимедиа, approval flow).
- **Этап 7:** Голос (Push-To-Talk, локальный Whisper STT, HTTP TTS / Windows TTS, липсинк).
- **Этап 8:** Интеграция характера и действий (тикер состояний, реакции на ошибки и победы).
- **Этап 9:** Системная интеграция и релиз (трей, хоткеи, автозагрузка, инсталлятор NSIS).
